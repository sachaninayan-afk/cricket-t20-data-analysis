# Cricket T20 Data Analysis

## Project Overview
This project analyzes T20 cricket data using Python, Pandas and Power BI.

## Tools Used
- Python
- Pandas
- NumPy
- Power BI
- DAX

## Dashboard
The Power BI dashboard provides insights into:
- Team performance
- Player performance
- Batting statistics
- Bowling statistics
- Match results
- Key performance indicators

## Files
- PowerBI/ → Power BI dashboard
- Data/ → Dataset files
- Screenshots/ → Dashboard preview

## How to Use
Download the .pbix file and open it using Power BI Desktop.
